
# Day-11 – Swagger (OpenAPI) Documentation

## Topics Covered

- Introduction to Swagger and OpenAPI
- Adding Swagger dependency using springdoc-openapi
- Configuring Swagger for Spring Boot
- Understanding Swagger UI
- Accessing Swagger at `/swagger-ui/index.html`
- Documenting REST APIs using:
  - @Tag
  - @Operation
  - @ApiResponse
  - @ApiResponses
- Writing professional API summaries and descriptions
- Documenting HTTP response codes (200, 201, 400, 404)
- Viewing interactive API documentation

## Key Learnings

- Swagger automatically generates REST API documentation.
- OpenAPI is the specification, while Swagger is the implementation tool.
- API documentation improves collaboration between frontend and backend teams.
- Every endpoint should have meaningful summaries, descriptions, and response documentation.
